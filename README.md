# JavaScript Learning Journey 🚀

Welcome to my JavaScript repository! This space is dedicated to my continuous learning and mastery of JavaScript. As a final-year B.Tech Computer Science student with a strong focus on full-stack web development, a deep understanding of JavaScript is the absolute foundation for my work with the MERN stack and Node.js.

## 📁 Repository Structure

This repository is organized to track my progress from basic syntax to advanced concepts. Based on my current workspace, you will find:

*   **`01basic/`**: Contains scripts and notes covering the core, foundational concepts of JavaScript.
*   **`hello.js`**: The initial entry point and first steps into the language.
*   **`JavaScript-/`**: Nested directory for specific topic deep-dives and version control practice.

## 🎯 Learning Objectives

Throughout this repository, I will be covering:
*   **Core Fundamentals:** Variables, data types, arrays, objects, and control flow.
*   **Functions & Scope:** Arrow functions, closures, and execution context.
*   **Advanced JavaScript:** Prototypes, ES6+ features, and object-oriented programming (drawing parallels from my experience with Java).
*   **Asynchronous JavaScript:** Callbacks, Promises, and Async/Await—crucial for robust backend API integrations in Node.js.
*   **DOM Manipulation:** Interacting with the browser to lay the groundwork for dynamic UIs in React.

## 👨‍💻 About the Author

I'm Manjeet Kumar Jha, a software engineering enthusiast passionate about building modern web applications. Whether I'm designing an AI-powered social media dashboard or structuring the backend for a full-stack Employee Management System, JavaScript remains at the core of my development toolkit.
